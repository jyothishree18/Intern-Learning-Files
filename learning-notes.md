### What is Open Source?
Open-source software is software whose code is available for people to view, modify, and share. “Free” can mean having the freedom to use and change the software.

### Is Open Source always free?
Not always. The software can be free, but you may have to pay for services like support, hosting, or additional features.

### Does “free” always mean money?
No. “Free” can mean freedom, not just free of cost. It can mean you are free to use, modify, and share the software.

### What is ORM and Hibernate in Java?
ORM connects objects in your code with tables in a database. Hibernate is a popular ORM framework used in Java.

### What is the equivalent in Python?
In Python, SQLAlchemy and Django ORM are commonly used for ORM.

### What is CRUD and how is it related to HTTP?
CRUD means Create, Read, Update, Delete. These are commonly mapped to HTTP methods:
Create → POST
Read → GET
Update → PUT/PATCH
Delete → DELETE

### What is API and Web API? How is Web API related to HTTP?
An API allows different software to communicate with each other. A Web API does this over the web, usually using HTTP to send requests and receive responses.
