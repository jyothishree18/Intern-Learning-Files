**1.What is WSL for? how is it related Linux as an Operating system.**

**Windows subsystem for Linux(WSL)**

\->feature of Windows that run as Linux environment directly on your Windows computer.

\->With WSL, you can install something like Ubuntu and use its Linux environment from Windows.



**2.WHat is the difference between Linux and Unix?**

Linux

\->free open source Unix like OS

\->Linux is based on many of the ideas and standards of Unix, but its not actually Unix itself.



Unix

\->Unix came first. Linux was created later

\->Often commercial and like an older parent of many operating systems, including Linux.



**3.IP and Public IP VS Private IP**

\->IP address is like a home address for a device on a network.

\->helps devices find and communicate with each other.



PUBLIC IP:

\->Used on the Internet

\->Identifies your network to the outside world



PRIVATE IP:

\->Used inside a local network

\->Identifies a device within our Wi-Fi



Internet → Public IP → Router → Private IP → laptop/phone



**4.Application Server, Webserver - what are these - Name some examples for Python.**



Application Server:

\->runs the app's logic

\->Example: Uvicorn



Webservers:

\->receives and delivers web requests

\->Example: Nginx



A user opens a website → Nginx receives the request → FastAPI running on Uvicorn processes it → the response goes back to the user.
