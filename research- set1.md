# Research Set 1

## 1. What is the HTTP protocol?

HTTP (HyperText Transfer Protocol) is a protocol used for communication between a client and a web server. It allows the client to send requests and the server to send responses.

## 2. What is a web application?

A web application is a software application that runs on a web server and can be accessed through a web browser. Examples include Gmail, YouTube, and online banking websites.

## 3. What is a web server?

A web server is a system that receives requests from clients and sends back web content or responses. Examples include Nginx.

## 4. What is the HTTPS protocol, and why is it considered secure?

HTTPS is the secure version of HTTP. It uses encryption to protect data sent between the client and server. It also uses a certificate to help verify that the user is communicating with the correct website.

## 5. What is authentication, and what is authorization?

Authentication means checking **who you are**.

Authorization means checking **what you are allowed to do**.

For example, logging into an account is authentication, while accessing an admin page is authorization.

## 6. How does social login work?

When we choose "Sign in with Google" or Facebook, the website redirects us to that service. After we log in and give permission, Google or Facebook confirms our identity to the website. The website can then create or log us into our account.

## 7. What is synchronous vs asynchronous communication?

**Synchronous:** The application waits for a response before continuing.

**Asynchronous:** The application can continue doing other work while waiting for the response.

For example, sending a request and waiting immediately for the result is synchronous, while sending a request and handling the result later is asynchronous.

## 8. What is REST?

REST (Representational State Transfer) is a set of recommendations for designing web APIs. It uses HTTP methods such as GET, POST, PUT, and DELETE to work with resources.
